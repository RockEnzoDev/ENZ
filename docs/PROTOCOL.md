# CoT プロトコル仕様

ENZ CoT(Chat of Things)シリーズの「共通語」。全機種がこの規約で会話する。
新機種はこの仕様に合わせること。
未知のタイプのパケットは黙って無視する(旧ファームとの互換維持のため)。

## 1. ESP-NOW チャット

### パケット(MsgPacket、packed、223 バイト固定)

| フィールド | 型 | 内容 |
|---|---|---|
| type | uint8 | 1 = HELLO、2 = CHAT、3 = VOICE(予約・未実装)、4 = POS(位置ビーコン、T-Deck v14〜) |
| to_mac | uint8[6] | 宛先MAC。全ゼロ = ブロードキャスト |
| name | char[16] | 送信者名(ニックネーム) |
| text | char[200] | 本文(UTF-8) |

### 規則

- HELLO は 5 秒ごと。相手のタイムアウトは 30 秒。同時ピアは最大 8。
- ピア一覧には Broadcast(全員宛て)の疑似ピアが常駐する。
- ニックネームは Preferences の名前空間 "msg" / キー "name"。
  未設定時の既定値は「<表示名>-<MAC下位2バイトの16進>」。
- チャンネル:
  - WiFi 接続中の機種は AP のチャンネルに追従する。
  - 単独機種は手動チャンネルを使う(既定 Ch1)。
    Preferences "chat" / "mch"(0 = Auto、1–13 = 固定)。
  - 通信する同士は同じチャンネルに合わせること。
- Long Range モード: Preferences "chat" / "lr"。
  使う場合は全機で LR に統一する(混在すると片方向になる場合がある)。

### 位置ビーコン(type 4、T-Deck v14〜)

- `text` に `latE6,lonE6,altM`(10 進 ASCII、緯度経度は 10^6 倍の整数、
  高度は m)を入れてブロードキャストする。
- 受信側は送信者ピアに位置を保持し(鮮度 30 分)、ピア一覧で
  距離・方角、地図画面でマーカー表示に使う。チャット行としては表示しない。
- 旧ファームは未知タイプとして無視するので、混在しても問題ない。

### SD カードのチャットログ

- パス: `/chats/<相手MAC 12桁16進>.log`、グループは `/chats/group.log`
- 1行の形式: `who|text`

## 2. LoRa(T-Deck、920 MHz 帯)

日本の ARIB STD-T108(920 MHz 帯 特定小電力)に沿うこと。

- 周波数 920.8 MHz(JP の Meshtastic / MeshCore 実験に合わせて統一)
- 変調プロファイルは切替式:
  - Std(標準): 帯域幅 125 kHz、SF8、符号化率 4/5
  - Narrow: 帯域幅 62.5 kHz、SF8、符号化率 4/6
    (NarrowSlow 実験と物理層を合わせたもの。Meshtastic そのものとの
    相互運用を保証するものではない)
- 実験中: MeshCore リスニングプロファイル(920.8 MHz、帯域幅 62.5 kHz、
  SF8、符号化率 4/5)。このプロファイルでは CoT の LoRa 送信を止め、
  受信した生パケットを RAW ログ画面に記録する。将来の目標は
  ESP-NOW(CoT 家族)⇄ MeshCore のブリッジ
  (LoRa メッシュの隙間を ESP-NOW で埋めるラストワンマイル構成)
- 送信電力 13 dBm 以下、送信前にキャリアセンス(LBT)必須
- フレーム: `[type][id16][nameLen][name][text]`
  (type: 1 = HELLO、2 = CHAT、3 = POS(位置ビーコン。text の形式は
  ESP-NOW の type 4 と同じ `latE6,lonE6,altM`。名前でピアに紐付ける))
- HELLO は 90 秒ごと
- LoRa 経由で届いた行は、表示名の後ろに `(L)` を付けて表示する
- ホーム画面のターミナルから送ると、ESP-NOW と LoRa の両方に出る

## 3. 音声 PTT(Phase 3、未実装)

- ESP-NOW の type 3 フレームで送る(テキスト互換は維持される)。
- 想定コーデック: ADPCM 8 kHz(約 4 KB/s)。
- LoRa では音声は送らない(占有時間の制約のため)。
- マイクの無い機種(CYD)は受信専用とする。

## 4. 共通 SD 資産

- `/jpfont16.bin` — 日本語フォント(マジック "ENZF"、16px)。
  無い機種・無い場合は英語のみの表示・入力になる。
- `/skk.dic` — SKK 形式辞書(「よみ /候補1/候補2/」)。
  無い場合はかな入力のみ(変換なし)。
- `/music` — 音楽ファイル置き場(MP3 / WAV、機種により対応が異なる)。
- `/picture` — CYD のスライドショー用画像置き場。
- `/presshist.bin` — CYD の気圧 24 時間履歴ミラー(CLEAN 版が読み書き)。
- `/maps/<z>/<x>/<y>.jpg` — T-Deck 地図画面用の国土地理院タイル
  キャッシュ。PC 側で `tools/gsi_cache.py` を使って用意する
  (出典: 国土地理院)。
