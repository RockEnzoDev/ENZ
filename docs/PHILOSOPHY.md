# ENZ CoT の設計思想

## ガジェットの「3 つの死」を拒否する

ガジェットは、たいてい「まだ使える」のに終わります。

- **ファームウェアの更新から取り残されて終わる** — メーカーが更新を
  やめた途端、脆弱性と仕様変更に置いていかれる
- **サービスが終了して終わる** — サーバーにぶら下がった玩具は、
  サーバーの寿命がそのまま自分の寿命になる
- **電池が死んで終わる** — 封入された電池が劣化したら、本体ごとゴミになる

そして 4 つ目が、**物理的な破壊で終わる**こと。これだけが正当な寿命です。
残りの 3 つは、使い手の都合ではなく作り手の都合で決まる死に方です。

ENZ CoT は、その 3 つを最初から拒否する設計にしています。

- ファームウェアは**自分で書ける**(オープンソースで公開し、Launcher で
  自分で配布できる)
- **サーバーを持たない**(端末同士が直接話す。止める者がいない回線は、
  終わらない)
- 電池は**交換できる汎用セル**(長寿命の LiFePO4 などを選べる)

## 専用機 + チャット

どの機種も「軸になる機能 + チャット」です。部屋時計、小型音楽
プレイヤー、ボイスレコーダー — まず「何の専用機か」があって、
チャットはそのオマケとして付いてきます。

これは順序の問題です。無線機を買っても、話す相手と置く場所が
付いてこなければ、結局使われなくなります。逆に、毎日使うモノに
チャットが付けば、会話の相手と置き場所は最初から決まっています。
**無線のための無線ではなく、モノのための無線**です。

## 網は自分で持つ

通信路は 2 階建てです。

- **ESP-NOW** — 家の中の「ラスト 10 メートル」。壁越しでも届き、
  設定なしで端末同士が直接話す
- **LoRa** — 軒先と軒先をつなぐ長距離側。日本の 920 MHz 帯の制度
  (ARIB STD-T108)に素直に沿って使える

両者を橋渡しするブリッジ端末が育てば、家の中の端末は LoRa 無線機を
持たなくても遠くと話せます。将来的には Wi-Fi HaLow (IEEE 802.11ah)
のような「一気に飛べる」リンクで、川のような置き場所のない区間を
越えることも構想しています。メッシュは小刻みでも、要所に太い橋が
あれば景色は変わります。

## 顔は Comic Chat へ

ターミナルの文字行は、作る側の都合の良い表示です。読む側にとって
自然なのは、**顔と吹き出し**です。

いずれこのチャットは、参加者ごとに顔を持ち、コマの中の吹き出しで
話す形 — 1996 年に Microsoft が公開した Comic Chat のような姿 — に
育てるつもりです。キーボードが打てなくても、「誰が何を言ったか」が
一目で分かる。それが、家族に配れる端末の最終形だと考えています。

## 普及が目的です

このリポジトリでやっていることは、種まきです。設計も、プロトコルも、
失敗の記録も公開します。

この考えに共感する企業や作り手がいて、製品化や別の実装が生まれる
なら、それは歓迎すべきことです。目的は「自分の作品を守ること」
ではなく、**そのへんにある玩具同士が、当たり前にチャットで
繋がる世界**だからです。
