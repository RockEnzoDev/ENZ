# Wi-Fi HaLow (IEEE 802.11ah) 調査ノート

T-Deck（無線番長）への HaLow 追加に向けた情報置き場。
制度が固まって着手するまでの間、ここに知見を貯める。

## 概要

- Wi-Fi HaLow = IEEE 802.11ah。Sub-1GHz 帯を使う長距離・低消費電力の
  Wi-Fi。Wi-Fi Alliance が 2021 年から認証プログラムを開始。
- 距離は最大 1km 級、スループットは最大 86 Mbps 級（チャンネル幅
  1/2/4/8/16 MHz）。LoRa より桁違いに速く、IP がそのまま通る。
- CoT での位置づけ: 長距離・高速な IP 伝送路。チャットだけでなく
  音声・ファイル転送まで射程に入る。

## 日本の制度状況（2026-10-30 時点）

- 用語辞典等の既存情報では、日本の HaLow は 920MHz 帯
  （916.7〜927.9 MHz）とされる。
- 一方、総務省「周波数再編アクションプラン（令和8年度版）（案）」には
  デジタル MCA 終了後の 800MHz 帯について「800MHz帯広域小電力無線
  システムは令和8年内に制度整備を行う」とあり、これが HaLow と
  どう関係するかは未確認（下記「知りたいこと」）。
- 関連のパブリックコメント（いずれも 2026-10 に終了）:
  - 案件 145210774「電波有効利用の推進に係る検討課題に対する意見募集」
  - 案件 145210777「周波数再編アクションプラン（令和8年度版）（案）」

## モジュール / チップ候補

- Morse Micro MM6108（HaLow SoC の本命。SPI/SDIO ホスト接続の
  モジュール製品が出始めている）
- 村田製作所の Wi-Fi HaLow モジュール
- NewraTek IW6300 等
- ICOM でも採用事例があるとの話（要確認）

## T-Deck 統合メモ

- ESP32-S3 に HaLow は載っていないため、外付けモジュールが前提。
  ホスト接続は SPI / SDIO が現実解。
- ESP32 ホスト向けのドライバ / ライブラリの整備状況は未調査。
- アンテナと RF は帯域確定後（920 か 800 かで変わる）。

## 知りたいこと

- 日本で HaLow に正式に割り当てられる帯域と技術的条件（出力、
  チャンネル幅、キャリアセンスの要否）はいつ・どう決まるか。
- 「800MHz帯広域小電力無線システム」と HaLow の関係。
- ESP32-S3 から MM6108 系モジュールを叩く既存実装の有無。
- ICOM の採用形態（どの製品に、どのモジュールか）。
