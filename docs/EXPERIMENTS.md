書式: 日付 / 対象 / 試したこと / 結果 / 分かったこと

## 2026-10-29 MeshCore 実験 Stage 1(受信のみ)

- 対象: T-Deck v12(MeshCore リスニングプロファイル)
- 試したこと: 920.8 MHz / BW62.5 / SF8 / CR 4/5 で受信専用にし、
  生パケットを RAW ログ画面に記録。相手は WADAMESH を焼いた
  もう1台の T-Deck を想定
- 結果: 実機確認待ち
- 分かったこと: (結果が出たら追記)

## 2026-10-28〜29 T-Deck 2号機のタッチパネル

- 対象: T-Deck 2号機
- 試したこと: フラッシュ後にタッチが死んだため、トラックボール
  カーソルを保険として実装(v9〜v10)
- 結果: タッチは自然復活。カーソルは残した
- 分かったこと: 原因は GT911 の故障ではなくフレキの接触不良の
  疑い。画面が出ない/入力が死んだら、まず接触を疑う

## 2026-10-28 T-Deck 初版の黒画面

- 対象: T-Deck v1
- 試したこと: 液晶の初期化を自前で書いて起動
- 結果: 画面が真っ黒のまま(ファーム自体は動作)
- 分かったこと: T-Deck の液晶設定は手書きしない。LilyGo 公式の
  LilyGo_T_Deck プロファイルを使う

## 2026-10-28 M5Core2 v1 の音楽再生

- 対象: M5Core2 v1
- 試したこと: UI スレッドから再生状態を直接読みに行く実装
- 結果: 画面が固まり、音もノイズ交じり
- 分かったこと: デコードタスクのファイルオブジェクトに UI は
  触らない。状態はスナップショット経由で読む(シリーズ共通の決まり)
